本网站汇总了实验室的服务器资源、数据集以及日常运维操作指南，方便新老成员快速上手。

📖 用户手册

  • 教程：使用 SSH 密钥连接实验室服务器 — 快速上手的分步骤教程。
  • 服务器 — 查看实验室所有服务器的硬件配置、IP 地址、端口转发规则及安全策略（防火墙 / SSH / 内网穿透）。
  • 数据集 — 浏览实验室已归档的数据集清单及其在 NAS 或本地磁盘上的存放路径。

🔧 运维手册

  • 系统重置流程 — Ubuntu Server 24.04 从安装到配置的完整步骤，涵盖驱动、防火墙、SSH 及常用工具。
  • 用户、管理员及权限操作 — 常用账户管理命令速查：添加/删除用户、赋予/撤销管理员、ACL 目录权限控制。
  • NAS 自动挂载 — 通过 systemd 实现 NFS 共享存储的开机自动挂载，避免手动挂载的麻烦。
