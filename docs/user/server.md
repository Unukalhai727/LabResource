### A6000 / 5090 安全策略：

- 防火墙：
    - 对实验室内网（10.31.112.0/24）开放全部入站端口
    - 对校园网（10.0.0.0/8）仅开放22入站端口
    - 对公网不开放入站端口
- SSH:
    - 关闭密码登录（仅允许密钥认证）

### 内网穿透策略：

- 使用frp和阿里云杭州服务器进行内网穿透，所有链路共享100M带宽
- 为了缓解爆破攻击，短时间内发起大量连接的IP会触发封锁
